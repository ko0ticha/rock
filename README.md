# Мой средний балл

Небольшое офлайн‑веб‑приложение на русском языке для подсчёта среднего балла и планирования желаемой оценки.

## Возможности

- добавление, редактирование и удаление предметов;
- дневник оценок по учебным датам с комментариями;
- текущий балл, желаемая оценка и количество оценок по каждому предмету;
- выбор системы учебных периодов: 4 четверти, 3 семестра или 2 семестра;
- выбор класса с 1 по 11 и сохранение класса/периода у каждой оценки;
- выбор дней обучения с проверкой даты при добавлении оценки;
- настройка границы перехода между оценками (например, `0,67`);
- расчёт общего среднего и необходимой следующей оценки;
- подробная аналитика: кривая среднего балла, фильтр по периоду и предмету, сравнение предметов и таблица итогов;
- план достижения результата: нужное количество оценок 3/4/5 и сценарии после исправления двоек;
- светлая и тёмная тема;
- сохранение в `localStorage`, без сервера и внешних зависимостей.

## Публикация на GitHub Pages

Загрузите содержимое репозитория в GitHub и включите `Settings → Pages → Deploy from a branch`, выбрав ветку с файлами проекта. Приложение состоит из статических файлов и готово работать на Pages без сборки.
